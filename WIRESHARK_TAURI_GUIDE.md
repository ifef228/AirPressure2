# Инструкция по мониторингу порта Tauri через Wireshark

## Обзор

Это руководство поможет вам настроить Wireshark для мониторинга сетевого трафика приложения Tauri, которое взаимодействует с бэкендом на порту **8080**.

## Информация о портах

- **Бэкенд API**: `http://localhost:8080/api`
- **Фронтенд (dev режим)**: `http://localhost:5173` (только для разработки)

## Установка Wireshark

### macOS
```bash
brew install wireshark
```

Или скачайте с официального сайта: https://www.wireshark.org/download.html

### Важно для macOS
После установки необходимо дать Wireshark права на захват пакетов:
1. Откройте **Системные настройки** → **Безопасность и конфиденциальность**
2. Перейдите в раздел **Конфиденциальность**
3. Выберите **Полный доступ к диску** (или **Запись на диск**)
4. Добавьте Wireshark и дайте ему необходимые разрешения

## Настройка Wireshark для мониторинга порта 8080

### Шаг 1: Запуск Wireshark

1. Откройте Wireshark
2. Выберите сетевой интерфейс для мониторинга:
   - **Loopback: lo0** (для localhost трафика на macOS)
   - Или ваш основной сетевой интерфейс (если бэкенд доступен по сети)

### Шаг 2: Настройка фильтра

В поле фильтра введите один из следующих вариантов:

#### Вариант 1: Фильтр по порту (рекомендуется)
```
tcp.port == 8080
```

#### Вариант 2: Только исходящие запросы к порту 8080
```
tcp.dstport == 8080
```

#### Вариант 3: Только входящие ответы с порта 8080
```
tcp.srcport == 8080
```

#### Вариант 4: HTTP трафик на порту 8080
```
tcp.port == 8080 && http
```

#### Вариант 5: Трафик с/на localhost:8080
```
(ip.addr == 127.0.0.1) && (tcp.port == 8080)
```

### Шаг 3: Начало захвата

1. Нажмите кнопку **Start capturing packets** (синяя иконка акулы) или выберите **Capture** → **Start**
2. Запустите ваше Tauri приложение
3. Выполните действия, которые генерируют сетевой трафик (например, отправку запросов к API)

## Анализ трафика

### Просмотр HTTP запросов

1. В списке пакетов найдите пакеты с протоколом **HTTP**
2. Кликните на пакет, чтобы увидеть детали
3. В нижней панели разверните:
   - **Hypertext Transfer Protocol** - для просмотра HTTP заголовков
   - **HTTP Request** или **HTTP Response** - для просмотра тела запроса/ответа

### Полезные фильтры для анализа

#### Показать только HTTP запросы
```
tcp.port == 8080 && http.request
```

#### Показать только HTTP ответы
```
tcp.port == 8080 && http.response
```

#### Показать запросы к конкретному эндпоинту
```
tcp.port == 8080 && http.request.uri contains "/api/users/login"
```

#### Показать POST запросы
```
tcp.port == 8080 && http.request.method == "POST"
```

#### Показать запросы с ошибками (4xx, 5xx)
```
tcp.port == 8080 && http.response.code >= 400
```

### Просмотр JSON данных

1. Найдите HTTP пакет с телом запроса/ответа
2. В деталях пакета найдите **Line-based text data** или **JavaScript Object Notation**
3. Кликните правой кнопкой → **Follow** → **HTTP Stream** для просмотра полного диалога

## Сохранение и экспорт данных

### Сохранение захвата
1. **File** → **Save As...**
2. Выберите формат (обычно `.pcapng` или `.pcap`)
3. Укажите имя файла

### Экспорт HTTP объектов
1. **File** → **Export Objects** → **HTTP**
2. Выберите нужные объекты
3. Нажмите **Save** для сохранения отдельных файлов

### Экспорт в JSON
1. Выберите нужные пакеты
2. **File** → **Export Packet Dissections** → **As JSON**
3. Укажите файл для сохранения

## Примеры использования

### Пример 1: Мониторинг авторизации

1. Установите фильтр: `tcp.port == 8080 && http.request.uri contains "/api/users/login"`
2. Запустите захват
3. Выполните вход в Tauri приложение
4. Просмотрите отправляемые credentials (будьте осторожны с безопасностью!)

### Пример 2: Мониторинг всех API запросов

1. Установите фильтр: `tcp.port == 8080 && http`
2. Запустите захват
3. Используйте приложение как обычно
4. Анализируйте все HTTP запросы и ответы

### Пример 3: Поиск ошибок

1. Установите фильтр: `tcp.port == 8080 && http.response.code >= 400`
2. Запустите захват
3. Выполните действия, которые могут вызвать ошибки
4. Просмотрите ответы с ошибками

## Альтернативные инструменты

Если Wireshark кажется слишком сложным, можно использовать:

### 1. tcpdump (командная строка)
```bash
# Захват трафика на порту 8080
sudo tcpdump -i lo0 -A 'tcp port 8080'

# С сохранением в файл
sudo tcpdump -i lo0 -w capture.pcap 'tcp port 8080'
```

### 2. netstat (проверка активных соединений)
```bash
# Показать активные соединения на порту 8080
netstat -an | grep 8080

# С процессом
lsof -i :8080
```

### 3. curl с verbose режимом
```bash
curl -v http://localhost:8080/api/users/profile
```

### 4. Встроенные инструменты браузера
- Chrome DevTools → Network tab
- Firefox Developer Tools → Network tab

## Решение проблем

### Проблема: Wireshark не видит localhost трафик

**Решение для macOS:**
1. Используйте интерфейс **Loopback: lo0**
2. Убедитесь, что у Wireshark есть права на захват пакетов
3. Попробуйте запустить Wireshark с правами администратора (не рекомендуется для безопасности)

### Проблема: Слишком много пакетов

**Решение:**
- Используйте более специфичные фильтры
- Остановите захват после выполнения нужных действий
- Используйте фильтры для исключения ненужного трафика

### Проблема: Не видно содержимое HTTPS

**Решение:**
- Если используется HTTPS, Wireshark покажет только зашифрованный трафик
- Для расшифровки нужен приватный ключ сервера
- В вашем случае используется HTTP на localhost, поэтому проблем быть не должно

## Безопасность

⚠️ **Важно:**
- Не перехватывайте трафик на производственных серверах без разрешения
- Будьте осторожны с сохранением пакетов, содержащих пароли и токены
- Удаляйте сохраненные файлы захвата после анализа
- Используйте фильтры для ограничения захвата только нужным трафиком
