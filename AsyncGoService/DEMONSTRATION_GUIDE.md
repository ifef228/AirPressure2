# Инструкция по демонстрации асинхронного сервиса через Postman

## Подготовка

1. Убедитесь, что запущены оба сервиса:
   - **Основной сервис** (Kotlin) на порту `8080`
   - **Асинхронный сервис** (Go) на порту `8081`

2. Запуск асинхронного сервиса:
   ```bash
   cd AsyncGoService
   MAIN_SERVICE_URL=http://localhost:8080 ASYNC_TOKEN=async123 go run main.go
   ```

3. Получите JWT токен для авторизации в основном сервисе (через Postman или интерфейс)

## Шаг 1: Получить список заявок (GET)

**Метод:** `GET`
**URL:** `http://localhost:8080/api/gas-orders`
**Headers:**
```
Authorization: Bearer <ваш_jwt_токен>
Content-Type: application/json
```

**Описание:**
Получаем список всех заявок. Обратите внимание на:
- `status` - статус заявки (должна быть `FORMED` или `COMPLETED`)
- `gases` - список газов в заявке
- `completedResultsCount` - количество полученных результатов (изначально 0)
- `tempResult` - итоговая температура (может быть `null`)

**Пример ответа:**
```json
{
  "success": true,
  "data": {
    "items": [
      {
        "id": 1,
        "status": "FORMED",
        "gases": [
          {
            "id": 1,
            "gasId": 1,
            "gasName": "Углекислый газ",
            "result": null
          }
        ],
        "completedResultsCount": 0,
        "tempResult": null
      }
    ],
    "total": 1,
    "page": 0,
    "size": 20
  }
}
```

**Важно:** Запишите `id` заявки и `gasId` первого газа для следующих шагов.

---

## Шаг 2: Вызвать асинхронный сервис через Postman

**Метод:** `POST`
**URL:** `http://localhost:8081/api/tasks`
**Headers:**
```
Content-Type: application/json
```

**Body (JSON):**
```json
{
  "type": "calculate",
  "data": "<calcOrderId>:<gasId>"
}
```

**Пример:**
Если заявка имеет `id = 1` и первый газ имеет `gasId = 5`, то:
```json
{
  "type": "calculate",
  "data": "1:5"
}
```

**Описание:**
Создаем задачу в асинхронном сервисе. Формат `data`: `calcOrderId:gasId` (ID заявки и ID газа через двоеточие).

**Пример ответа:**
```json
{
  "id": "task-1234567890123456789",
  "type": "calculate",
  "data": "1:5",
  "status": "pending",
  "created_at": "2025-01-15T10:00:00Z",
  "updated_at": "2025-01-15T10:00:00Z"
}
```

**Важно:** Запишите `id` задачи для проверки статуса.

**Примечание:** Если кнопки нет, можно использовать только Postman (Шаг 2).

## Шаг 4: Проверить статус задачи (опционально)

**Метод:** `GET`
**URL:** `http://localhost:8081/api/tasks?id=<task_id>`
**Headers:** Не требуются

**Описание:**
Проверяем статус задачи. Статусы:
- `pending` - задача в очереди
- `processing` - задача обрабатывается
- `completed` - задача завершена

**Пример ответа:**
```json
{
  "id": "task-1234567890123456789",
  "type": "calculate",
  "data": "1:5",
  "status": "completed",
  "result": "Temperature calculated for gas 5: 15.80°C",
  "created_at": "2025-01-15T10:00:00Z",
  "updated_at": "2025-01-15T10:05:00Z"
}
```

---

## Шаг 5: Подождать 5-10 секунд

**Описание:**
Асинхронный сервис обрабатывает задачу примерно 5 секунд, затем автоматически отправляет результат в основной сервис.

**Что происходит:**
1. Асинхронный сервис рассчитывает температуру
2. Автоматически отправляет результат на `POST /api/gas-orders/async-results` с заголовком `X-Async-Token: async123`
3. Основной сервис обновляет `result` в `GasOrder` и пересчитывает `tempResult` в `CalcOrder`

## Шаг 6: Снова получить список заявок (GET)

**Метод:** `GET`
**URL:** `http://localhost:8080/api/gas-orders`
**Headers:**
```
Authorization: Bearer <ваш_jwt_токен>
Content-Type: application/json
```

**Описание:**
Проверяем, что результат появился с задержкой. Теперь должны увидеть:
- `completedResultsCount` увеличился (например, с 0 до 1)
- В `gases[0].result` появилось значение (например, `15.80`)
- `tempResult` обновился (например, `15.80`)

**Пример ответа:**
```json
{
  "success": true,
  "data": {
    "items": [
      {
        "id": 1,
        "status": "COMPLETED",
        "gases": [
          {
            "id": 1,
            "gasId": 1,
            "gasName": "Углекислый газ",
            "result": 15.80
          }
        ],
        "completedResultsCount": 1,
        "tempResult": 15.80
      }
    ],
    "total": 1,
    "page": 0,
    "size": 20
  }
}
```

**Демонстрация:** Покажите, что результат появился после задержки (5-10 секунд).

---

## Шаг 7: Обновить результат вручную с ключом (для модератора)

**Метод:** `POST`
**URL:** `http://localhost:8080/api/gas-orders/async-results`
**Headers:**
```
Content-Type: application/json
X-Async-Token: async123
```

**Body (JSON):**
```json
{
  "results": [
    {
      "calcOrderId": 1,
      "gasId": 5,
      "result": 25.50
    }
  ]
}
```

**Описание:**
Имитируем отправку результата от асинхронного сервиса с новым значением. Этот метод требует токен `X-Async-Token: async123` (8 байт токен).

**Пример ответа:**
```json
{
  "success": true,
  "message": "Принято результатов: 1, обновлено заявок: 1",
  "data": "Принято результатов: 1, обновлено заявок: 1"
}
```

**Важно:**
- Токен должен быть точно `async123` (8 символов)
- `calcOrderId` - ID заявки
- `gasId` - ID газа
- `result` - новое значение результата (температура)

## Полная последовательность для демонстрации

1. ✅ **GET** `/api/gas-orders` - получить список заявок (результатов еще нет)
2. ✅ **POST** `http://localhost:8081/api/tasks` - создать задачу в асинхронном сервисе
3. ⏳ **Подождать 5-10 секунд** - асинхронный сервис обрабатывает задачу
4. ✅ **GET** `/api/gas-orders` - проверить, что результат появился с задержкой
5. ✅ **POST** `/api/gas-orders/async-results` с `X-Async-Token: async123` - обновить результат вручную
6. ✅ **GET** `/api/gas-orders` - проверить, что результат изменился

## Важные замечания

1. **Токен асинхронного сервиса:** `async123` (8 символов, задается через переменную окружения `ASYNC_TOKEN`)
2. **Формат данных задачи:** `calcOrderId:gasId` (например, `1:5`)
3. **Время обработки:** примерно 5 секунд (задается в коде: `time.Sleep(5 * time.Second)`)
4. **Автоматическая отправка:** асинхронный сервис автоматически отправляет результат обратно в основной сервис
5. **Ручное обновление:** можно вручную обновить результат через `POST /api/gas-orders/async-results` с токеном

## Troubleshooting

### Проблема: Результат не появляется

**Решение:**
1. Проверьте, что асинхронный сервис запущен на порту 8081
2. Проверьте логи асинхронного сервиса
3. Убедитесь, что `MAIN_SERVICE_URL` правильно настроен
4. Проверьте, что токен `ASYNC_TOKEN` совпадает (`async123`)

### Проблема: Ошибка 401 при обновлении результата

**Решение:**
1. Убедитесь, что заголовок `X-Async-Token` установлен
2. Проверьте, что значение токена точно `async123` (без пробелов)

### Проблема: Заявка не найдена

**Решение:**
1. Убедитесь, что заявка существует и имеет статус `FORMED` или `COMPLETED`
2. Проверьте, что `calcOrderId` и `gasId` правильные
3. Убедитесь, что газ действительно добавлен в заявку
