# Инструкция по импорту коллекции Postman

## Импорт коллекции

1. Откройте Postman
2. Нажмите **Import** (кнопка в левом верхнем углу)
3. Выберите файл `Async-Service-Postman-Collection.json`
4. Коллекция будет добавлена в ваше рабочее пространство

## Настройка переменных

После импорта настройте переменные коллекции:

1. Откройте коллекцию **"AsyncGoService - Демонстрация асинхронного сервиса"**
2. Перейдите на вкладку **Variables**
3. Установите значения:

| Переменная | Значение | Описание |
|------------|----------|----------|
| `base_url` | `http://localhost:8080` | URL основного сервиса |
| `async_url` | `http://localhost:8081` | URL асинхронного сервиса |
| `jwt_token` | `<ваш_jwt_токен>` | JWT токен для авторизации в основном сервисе |
| `async_token` | `async123` | Токен асинхронного сервиса (уже установлен) |

**Важно:**
- `calc_order_id` и `gas_id` заполняются автоматически после выполнения первого запроса
- `task_id` заполняется автоматически после создания задачи

## Получение JWT токена

Если у вас еще нет JWT токена, используйте существующую коллекцию `Gas-API-Postman-Collection.json`:

1. Выполните запрос **"Вход (Login) - Получить JWT токен"**
2. Токен автоматически сохранится в переменную `jwt_token`
3. Скопируйте токен и вставьте в переменную `jwt_token` в новой коллекции

Или выполните запрос вручную:
```
POST http://localhost:8080/api/users/login
Content-Type: application/json

{
    "login": "testuser",
    "password": "password123"
}
```

## Порядок выполнения запросов

1. **Получить список заявок (начальный)** - автоматически сохранит ID заявки и газа
2. **Создать задачу в асинхронном сервисе** - создаст задачу для расчета
3. **Проверить статус задачи (опционально)** - можно пропустить
4. **⏳ Подождать 5-10 секунд** - асинхронный сервис обрабатывает задачу
5. **Получить список заявок (после обработки)** - проверить, что результат появился
6. **Обновить результат вручную с ключом** - изменить результат через API
7. **Получить список заявок (финальная проверка)** - проверить, что результат изменился

## Автоматизация

Коллекция содержит скрипты, которые автоматически:
- Сохраняют ID заявки и газа после первого запроса
- Сохраняют ID задачи после создания
- Выводят полезную информацию в консоль

## Просмотр логов

В Postman откройте консоль (View → Show Postman Console) для просмотра автоматических сообщений от скриптов.

## Troubleshooting

### Ошибка 401 при получении списка заявок
- Проверьте, что `jwt_token` установлен и валиден
- Получите новый токен через запрос логина

### Ошибка 401 при обновлении результата
- Проверьте, что заголовок `X-Async-Token` установлен
- Убедитесь, что значение токена `async123` (8 символов)

### Результат не появляется
- Убедитесь, что асинхронный сервис запущен на порту 8081
- Подождите больше времени (5-10 секунд)
- Проверьте логи асинхронного сервиса

### Переменные не заполняются
- Убедитесь, что первый запрос выполнен успешно
- Проверьте, что в ответе есть заявки с газами
