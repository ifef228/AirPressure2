# 🌐 Настройка GitHub Pages для работы с локальным бэкендом

## Проблема
GitHub Pages работает по HTTPS, а ваш бэкенд на локальной сети. Нужно настроить проксирование запросов к локальному бэкенду.

## Решение

### Вариант 1: Автоматическое определение IP (рекомендуется)

Приложение автоматически определит ваш локальный IP и настроит подключение к бэкенду.

#### Шаг 1: Убедитесь, что бэкенд доступен в локальной сети

Бэкенд уже настроен на `address: 0.0.0.0`, что позволяет подключаться по IP локальной сети.

#### Шаг 2: Запустите бэкенд с профилем dev (HTTP)

```bash
cd gas
./gradlew bootRun --args='--spring.profiles.active=dev'
```

#### Шаг 3: Определите ваш локальный IP

**Автоматически (рекомендуется):**

Запустите скрипт для автоматического определения IP:

```bash
cd atmosphere-calculator
node scripts/get-local-ip.js
```

Скрипт покажет все доступные локальные IP адреса и рекомендации по настройке.

**Вручную:**

**Mac/Linux:**
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

**Windows:**
```bash
ipconfig
```

Найдите IP адрес вашей локальной сети (обычно начинается с `192.168.` или `10.`).

#### Шаг 4: Обновите конфигурацию в main.tsx

Откройте `atmosphere-calculator/src/main.tsx` и обновите значение по умолчанию (около строки 50):

```typescript
const defaultIp = 'YOUR_LOCAL_IP'; // Замените на IP из скрипта
```

Например:
```typescript
const defaultIp = '192.168.1.13'; // Замените на ваш IP
```

**Альтернатива:** Можно установить IP через консоль браузера на GitHub Pages:
```javascript
localStorage.setItem('backend_url', 'http://YOUR_LOCAL_IP:8080');
location.reload();
```

#### Шаг 5: Обновите CORS на бэкенде

Откройте `gas/src/main/kotlin/ru/mstu/yandex/gas/config/CorsConfig.kt` - CORS уже настроен на разрешение всех origin'ов для разработки.

#### Шаг 6: Соберите и задеплойте

```bash
cd atmosphere-calculator
npm run build
npm run deploy
```

### Вариант 2: Использование ngrok (для доступа через интернет)

Если нужен доступ через интернет (не только локальная сеть):

1. Установите ngrok: `brew install ngrok` или скачайте с https://ngrok.com
2. Зарегистрируйтесь и получите authtoken
3. Запустите туннель: `ngrok http 8080`
4. Скопируйте HTTPS URL (например: `https://abc123.ngrok-free.app`)
5. Обновите `main.tsx`: `const backendUrl = 'https://abc123.ngrok-free.app';`
6. Пересоберите и задеплойте

### Вариант 3: Ручная настройка через UI

Приложение может определить IP автоматически. Если это не работает:

1. Откройте консоль браузера на GitHub Pages
2. Введите ваш локальный IP в формате: `http://192.168.1.13:8080`
3. Приложение сохранит настройку в localStorage

## 🔧 Настройка бэкенда

### Для локальной сети (HTTP):

1. Запустите с профилем `dev`:
```bash
./gradlew bootRun --args='--spring.profiles.active=dev'
```

2. Бэкенд будет доступен по:
- `http://localhost:8080` (локально)
- `http://YOUR_LOCAL_IP:8080` (из локальной сети)

### Проверка доступности:

```bash
# С другого устройства в той же сети
curl http://YOUR_LOCAL_IP:8080/api/gases
```

## 📱 Использование

1. Откройте GitHub Pages: `https://YOUR_USERNAME.github.io/AirPressure2/`
2. Приложение автоматически попытается определить ваш локальный IP через WebRTC
3. Если автоматическое определение не сработало:
   - Используется IP по умолчанию из `main.tsx`
   - Или установите IP вручную через консоль браузера:
     ```javascript
     localStorage.setItem('backend_url', 'http://YOUR_LOCAL_IP:8080');
     location.reload();
     ```
4. Проверьте консоль браузера - там будут логи о подключении к бэкенду

## ⚠️ Важно

- Бэкенд должен быть запущен, пока используется сайт
- Устройства должны быть в одной локальной сети
- Для доступа через интернет используйте ngrok или cloudflare tunnel
- GitHub Pages работает по HTTPS, но service worker проксирует запросы на HTTP бэкенд в локальной сети

## 🐛 Отладка

1. Откройте DevTools → Application → Service Workers
2. Проверьте, что Service Worker активен
3. В консоли проверьте логи: `[Service Worker]` и `[API]`
4. Проверьте Network tab - запросы должны идти на ваш локальный IP
