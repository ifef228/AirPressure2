# Настройка GitHub Pages для подключения к бэкенду

## ✅ Что уже настроено

1. **Service Worker** перехватывает запросы к `/api` и перенаправляет на бэкенд `192.168.1.13:8080`
2. **Base path** настроен на `/airPressure/` для GitHub Pages
3. **API URL** автоматически использует правильный путь в production

## 🚀 Как это работает

1. Пользователь открывает GitHub Pages: `https://ifef228.github.io/airPressure/`
2. Приложение делает запрос к `/airPressure/api/gases`
3. Service Worker перехватывает запрос
4. Service Worker перенаправляет на `http://192.168.1.13:8080/api/gases`
5. Бэкенд отвечает, Service Worker возвращает ответ приложению

## ⚠️ Важно

**Service Worker работает только если:**
- Пользователь находится в той же локальной сети, что и бэкенд (192.168.1.13)
- Бэкенд запущен и доступен по IP `192.168.1.13:8080`
- CORS настроен на бэкенде для разрешения запросов с GitHub Pages

## 🔧 Если нужно изменить IP адрес

Откройте `src/main.tsx` и найдите строку:
```typescript
ip: '192.168.1.13',
```

Измените на ваш IP адрес.

## 📝 Деплой на GitHub Pages

```bash
npm run build
npm run deploy
```

После деплоя приложение будет доступно по адресу:
`https://ifef228.github.io/airPressure/`
